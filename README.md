# Near Website

The official promotional and informational website for the **Near** iOS application — a next-generation, privacy-first platform that lets you understand your surroundings on your own terms.

## 🚀 Tech Stack

This website is built with modern, high-performance web technologies:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons & UI:** Custom SVGs, fluid layout, and CSS mix-blend modes
- **Linting:** ESLint

## 📦 Getting Started

First, install the dependencies:

```bash
npm install
```

Next, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the site.

## 🎨 Design Language

The Near website is designed to reflect the premium, native feel of the iOS application. Key design elements include:
- A signature vibrant orange accent color (`#ff2b00`)
- Sleek, "squircle" (`rounded-[22.5%]`) shapes for app icons matching Apple's Human Interface Guidelines
- Clean, accessible dark typography on light backgrounds
- Subtle backdrop blurring (`backdrop-blur-md`) for floating elements like the navigation bar
